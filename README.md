# TAHL Tracker 🏒

AI-generated game recaps and articles for the **Tulsa Adult Hockey League**.

🌐 **Live site:** [stevenpurn.github.io/tahl-tracker](https://stevenpurn.github.io/tahl-tracker/)

## What It Does

TAHL Tracker automatically generates hockey articles and game recaps for our adult league in Tulsa. No more waiting for someone to write up last night's game — just show up, play, and let the AI handle the press box.

## Features

- 📰 AI-written game recaps and league articles
- 🏆 Coverage of the Tulsa Adult Hockey League
- ⚡ Automatically published to GitHub Pages

## Tech Stack

- **AI:** for article generation
- **Hosting:** GitHub Pages
- **League:** Tulsa Adult Hockey League (TAHL)
